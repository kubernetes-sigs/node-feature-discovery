# Contributing

---

## Community

You can reach us via the following channels:

- [#node-feature-discovery](https://kubernetes.slack.com/messages/node-feature-discovery)
  channel in [Kubernetes Slack](https://slack.k8s.io/)
- [SIG-Node](https://groups.google.com/a/kubernetes.io/g/sig-node) mailing list
- File an
  [issue](https://github.com/kubernetes-sigs/node-feature-discovery/issues/new)
  in this repository

## Contributing code

This project follows the Kubernetes contribution process. Read the
[Kubernetes contributor guide](https://www.kubernetes.dev/docs/guide/) and sign
the CNCF Contributor License Agreement (the EasyCLA bot prompts you on your
first pull request, see
[CLA.md](https://github.com/kubernetes/community/blob/main/CLA.md)). The
[developer guide](../developer-guide/index.md) describes how to build and test
NFD. Open an
[issue](https://github.com/kubernetes-sigs/node-feature-discovery/issues/new)
to discuss larger changes before submitting a pull request.

## Governance

This is a
[SIG-node](https://github.com/kubernetes/community/blob/main/sig-node/README.md)
subproject, hosted under the
[Kubernetes SIGs](https://github.com/kubernetes-sigs) organization in Github.
The project was established in 2016 and was migrated to Kubernetes SIGs in 2018.
